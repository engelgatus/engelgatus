### Hey there 👋

I'm Engel, a web designer, developer, and automation builder based in Makati, Philippines.

I transitioned from the service industry to tech in 2019 through Zuitt's coding bootcamp. These days, I design and build conversion-focused websites and engineer automation workflows that eliminate manual work and scale operations. I actually discovered automation at a previous role when I was thrown into Airtable for the first time — never heard of it before, but ended up rebuilding the entire database, workflows, and dashboards internally.

**What I'm working on:**
- **Web Designer & Developer at Trusted Digital** — Designing and building fast, conversion-focused WordPress sites for Australian local businesses using Figma and Elementor, from SEO briefs and low-fidelity wireframes
- Building scalable digital infrastructure with Next.js, React, TypeScript, and Tailwind CSS
- Engineering n8n automation workflows that cut manual processes
- Scraping and automating job discovery with Discord bots
